# Native migration contracts

The requested app is a real Windows desktop client. C# .NET 10 WPF, no Electron/WebView/Chromium/HTML/JavaScript runtime. WASAPI native audio using NAudio 2.2.1. Main UI WPF styled dark lime/lavender, custom DrawingContext stage. All namespaces MuWorld.Native (or .Core/.Audio/.Controls as below).

Shared models owned by core agent in native/MuWorld.Native/Core/Models.cs. Public POCO records/classes with PascalCase properties, JSON case insensitive/camelCase compatible for pre-exported content. Core namespace MuWorld.Native.Core.
