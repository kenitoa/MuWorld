# MuWorld — Rhythm Studio

차분한 음악 라이브러리, 선명한 4키 플레이 화면, 실제 입력으로 계산하는 성장 분석을 갖춘 오프라인 리듬게임입니다. Windows 데스크톱 앱으로 실행하며 게임용 서버나 계정이 필요하지 않습니다.

**바로 실행하려면** 배포 폴더의 `MuWorld.exe`를 엽니다.

```text
release/MuWorld-win32-x64/MuWorld.exe
```

배포 폴더 전체를 함께 보관하세요. 실행 파일 옆의 `resources`와 Chromium 관련 파일도 실행에 필요합니다. 패키징된 앱은 Node.js를 별도로 설치하지 않아도 실행됩니다.

**소스에서 실행하려면** Node.js 22.12 이상과 npm을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
npm install
npm start
```

`npm start`는 `scripts/run.mjs`를 통해 화면을 빌드하고 Electron을 실행합니다. 의존성 설치와 개발 환경의 첫 Electron 런타임 준비에는 인터넷이 필요할 수 있습니다. 준비된 앱의 플레이·분석·설정·음원 생성은 오프라인으로 동작합니다.

현재 Windows 환경에서 Node.js가 PATH에 등록되지 않았다면 다음처럼 실행할 수 있습니다. 의존성은 먼저 설치되어 있어야 합니다.

```powershell
& 'C:\Program Files\nodejs\node.exe' scripts/run.mjs
```

**처음에는 음악을 선택하고 입문 난이도로 시작해 보세요.** 기본 조작은 다음과 같습니다.

| 조작 | 동작 |
|---|---|
| `D / F / J / K` | 왼쪽부터 네 레인 입력 |
| 길게 연결된 노트 | 시작에 맞춰 누르고 끝까지 유지 |
| `Esc` | 플레이 일시정지 |
| 음악 선택 화면의 `↑ / ↓` | 선택 음악 변경 |
| 음악 선택 화면의 `Enter` | 선택한 채보 시작 |
| 음악 선택 화면의 `Space` | 미리 듣기 시작·중지 |

키는 환경 설정에서 바꿀 수 있습니다. 다른 창으로 이동하면 본편은 자동으로 일시정지합니다. 일시정지 후 이어 한 기록은 해당 상태가 표시되고, 중단 없이 완료한 일반 기록과의 성장 비교에서는 제외됩니다.

처음 선택한 곡과 배속은 잠깐 준비 시간이 있습니다. 모든 음악을 앱 내부에서 합성하며, 최근에 준비한 곡·배속은 메모리에 캐시합니다. 별도 음원 다운로드는 하지 않습니다.

**현재 들어 있는 콘텐츠와 도구입니다.**

| 기능 | 내용 |
|---|---|
| 오리지널 음악 | Glasshouse, Afterglow, Paper Moon, Velvet Current, Daybreak |
| 본편 채보 | 5곡 × 입문·기본·도전 = 15개 |
| 연습 스튜디오 | 4단계 실습 튜토리얼, 12개 패턴 훈련, 구간 선택, 50~100% 감속, 3·5회 자동 반복, 메트로놈 |
| 성장 분석 | 타이밍 분포, 평균·중앙값·MAD·표준편차·95백분위, 레인·패턴·구간·홀드·동시치기 분석 |
| 기록 | 일반·연습 기록, 동일 조건 비교, 리플레이, 개별 판정 CSV, 실제 기록으로 달성하는 5개 성취 배지 |
| 리듬 아케이드 | 에코 스튜디오, 빈 박자 챌린지, 비트 공방, 리듬 가드, 비트 루트 |
| 화면 조절 | 편안한 화면·선명한 화면·고대비, 레인 폭·노트 밝기·배경·효과·메뉴 크기 |
| 타이밍 설정 | 입력·시각 보정, 32회 탭 체감 보정, 이름을 붙여 저장하는 보정 프로필 |
| 로컬 데이터 | 설정·기록 저장, JSON 백업 내보내기·가져오기 |

연습은 결과 화면의 **같은 구간 반복**으로 이어가거나 시작 전에 3·5회 자동 반복을 선택할 수 있습니다. 자동 속도 상승을 켜면 정확도 95% 이상을 3회 연속 달성한 뒤 다음 반복을 시작할 때 속도가 5% 올라갑니다. 감속은 음악과 채보에 함께 적용되며 음높이를 유지합니다.

**5ms 설정은 판정 계산에 그대로 적용됩니다.** 입력 보정 +5ms는 늦게 기록된 입력을 5ms 앞당겨 평가한다는 뜻입니다. 기본 판정 허용폭은 PERFECT ±20ms, GREAT ±45ms, GOOD ±80ms, BAD ±120ms이며, 입력 보정과는 별개입니다. 설정은 정수 마이크로초로 보존합니다.

연습의 **정밀 판정**은 전체 판정창을 0.25배로 줄여 PERFECT를 ±5ms로 만듭니다. 이때 GREAT는 ±11.25ms, GOOD은 ±20ms, BAD는 ±30ms입니다. 일반 플레이 기록과는 구분됩니다.

32회 탭 보정은 사람의 타격 습관을 포함한 체감 보정입니다. 출력 지연 정보 역시 장치가 제공하는 추정치입니다. 키보드 접점·USB·운영체제·화면·실제 음향까지 포함한 **물리 오차 0ms를 보장하지 않습니다**. 보정값은 사용자가 적용해야 저장됩니다.

**데이터는 이 기기에 저장합니다.** 데스크톱 앱은 Electron 사용자 데이터 폴더의 로컬 저장소를 사용하고, 브라우저에서 화면만 열어 확인하는 경우에는 해당 브라우저의 저장소를 사용합니다. 중요한 기록은 환경 설정의 **백업 내보내기**로 JSON 파일을 보관하세요. 백업에는 설정, 본편·연습 기록과 리플레이, 즐겨찾기, 아케이드 요약 기록, 보정 프로필이 함께 들어갑니다. CSV는 개별 플레이의 판정 분석용이며 전체 복원용 백업과는 다릅니다. 백업 가져오기는 현재 데이터를 백업 내용으로 교체하므로, 앱은 먼저 기존 데이터의 백업 다운로드를 시작합니다.

**개발·검증 명령입니다.**

```powershell
npm run build      # 서버 없이 dist/에 화면 빌드
npm test           # 판정·음원 데이터·분석·보정·저장 테스트
npm run test:ui    # Electron 화면 및 동작 검사
npm run package    # Windows x64 배포 폴더 생성
```

단위 테스트는 판정 경계, 정확한 보정 적용, 배속 계산, 홀드, 지연 입력 재처리, 프레임 간격과 무관한 리플레이, 통계와 데이터 검증을 다룹니다. Electron UI 검사에서는 실제 키보드 이벤트로 플레이하고 결과·리플레이·재로드 후 저장 상태를 확인합니다. 검사 결과와 화면 캡처는 `artifacts/`에 생성됩니다. 실제 장비 전체의 지연이나 모든 PC의 120FPS를 인증하는 테스트는 아닙니다. 구현 범위와 남은 검증은 [구현 명세](docs/IMPLEMENTATION.md)에 정리했습니다.
