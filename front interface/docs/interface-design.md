# MuWorld 인터페이스 디자인

## 목적과 구현 순서

기존의 어두운 남색과 푸른 강조색을 유지하면서 화면별 글자·버튼·조작 영역의 불일치를 줄인다.
공통 팔레트와 버튼 → 이미지 의존 없는 라이브러리 → 메인·설정 → 연습·필터 → 결과·에디터 순으로 적용한다.
변경 범위는 WinForms 표현과 조작 계층이며 판정 엔진, 점수 계약, 차트 저장 포맷은 유지한다.

## 공통 규칙

- 기본 배경 #080C16, 패널 #101827, 떠 있는 면 #182338, 경계 #2B3952.
- 글자 #EDF2FC, 보조 글자 #A7B4CA, 주요 행동 #8CAFFF.
- 버튼은 채운 주요 행동과 차분한 보조 행동을 구분한다.
- 일반 글자는 문자별 자간을 벌리지 않고 한 문자열로 측정·표시한다.
- 고정 공간의 숫자와 버튼 이름은 실제 글자 크기를 측정해 경계 안에 표시한다.
- 그리기와 클릭·접근성에 같은 bounds 함수를 사용한다.
- 라이브러리는 1672×941 논리 공간을 창 안에 맞추고 초광폭에서 중앙 정렬한다.
  배경 이미지의 글자나 버튼을 덮어 그리는 방식을 사용하지 않는다.

## 화면별 적용

- 메인: 곡 선택을 주요 행동으로, 첫 연습을 그 아래에 배치한다.
  앱 재시작은 실제 동작을 이름에 명시한 보조 행동이다.
- 곡 선택: 검색·정렬·필터·연속 행 이동, 키 모드 4K~7K,
  Rescan/Details/Replay/Editor 진입, 활성 필터 설명과 Clear를 표시한다.
  커버는 정사각형, 전체 차트 기준 개인 최고 점수는 그 범위를 명시한다.
  표시되는 행과 마우스/접근성으로 선택하는 곡이 같은 인덱스를 사용한다.
- 설정: 변경은 미리보기이고 Apply가 저장한다. Cancel/ESC/Back은 마지막 적용 상태를 복원한다.
  설정 하위 키 설정·보정 화면에서도 초안 저장을 억제한다.
  RESET ALL은 전체 초기화라는 범위를 표시한다.
  음악·미리듣기 음량을 실제 데이터 의미에 맞춰 표시하고 히트 사운드는 긍정형 토글이다.
- 연습: 게임 창의 클라이언트 영역을 채우는 테두리 없는 owned modal이다.
  별도 Form의 입력·오디오 수명은 유지하며 화면 색상과 버튼은 본게임과 통일한다.
  Escape로 종료할 수 있다. 실제 게임과 동일한 엔진을 사용한다.
- 필터: 게임 내부 오른쪽에 정렬되는 어두운 owned modal.
  표준 컨트롤의 키보드·접근성을 유지한다.
- 결과: 실패 시 Retry, 성공 시 Song Select를 강조한다.
  미완료 결과의 NO MISS와 입력이 없는 상태의 일반적인 타이밍 조언을 제거한다.
  점수와 판정 수치는 전체 값을 경계 안에 표시한다.
- 에디터: 문서 도구, 편집 도구, 변형/속성 도구를 나눈다.
  EDIT VALUES에서 BPM·선택 노트 시간·레인·길이·끝 레인을 수정한다.
  비유한 값, 범위 위반, 겹침은 전체 적용 전에 거부하며 성공한 수정은 Undo로 되돌린다.
  밀도 그래프의 테두리는 현재 보는 구간이고 그래프 클릭은 해당 시점으로 이동한다.
- 인게임: 큰 로고를 키 모드 표시로 바꾸고 속도 조작부를 작게 정리한다.
  판정·레인·입력 규칙은 변경하지 않는다.

## 데이터 흐름과 위험 관리

사용자 입력 → 공유 bounds → 기존 action → 상태 변경 → 다시 그리기.
설정은 진입 스냅샷 → 런타임 미리보기 → Apply 시 영속화,
Cancel 시 스냅샷 적용 순서이다.
속성 편집은 후보 노트 목록 → 경계·차트 검증 → Undo 스냅샷 → 적용 순서이다.

주요 위험은 확대 글자의 잘림, 접근성 영역과 그림의 불일치,
설정 미리보기가 취소 이후 남는 문제이다. 추가 테스트와 해상도별 캡처로 확인한다.
새 데이터베이스, 환경 변수, 런타임 의존성은 없다.

## 검증과 복구

- 별도 artifacts 경로에서 Debug/Release 빌드와 self-test를 실행한다.
- 라이브러리 960×640, 1366×768, 1920×1080, 2560×1080 및 글자 100/125/140% 캡처.
- 신규 조작의 hit target과 viewport 내부 배치, 연속 선택, 필터 초기화를 검사한다.
- 설정 취소/적용 후 취소/영속화와 속성 편집 검증/Undo를 검사한다.
- 기존 화면·판정·리플레이 테스트를 유지한다.
- 실제 Windows DPI 125/150%, screen reader 및 사람 입력으로 전체 흐름을 확인하는 작업은 별도 수동 검증이다.
- 복구는 이 UI 변경의 소스만 이전 버전으로 되돌리고 다시 빌드한다.
  사용자 설정·기록·차트 삭제나 데이터 이전은 필요하지 않다.
